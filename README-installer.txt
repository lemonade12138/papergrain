QUICK START
-----------
- Launch PaperGrain.exe. A paper-grain icon appears in the system tray
  and the texture overlay is active immediately.
- Press Ctrl+Shift+P to toggle the overlay on/off.
- Left-click the tray icon to open Settings.
- Right-click the tray icon for the full menu:
  texture presets, opacity, per-monitor toggles, auto-start, exit.

WHAT TO KNOW
------------
- The overlay is click-through: it never blocks mouse or keyboard input.
- Before sharing or recording your screen, toggle the overlay off
  (Ctrl+Shift+P) - screen capture tools will otherwise record the texture.
- Settings are stored in %APPDATA%\PaperGrain\config.json.
- Custom textures (PNG/JPG/BMP/GIF) can be loaded via Settings -> Browse.
  The four preset textures are procedural - no image files are needed.
- No network access. No telemetry. MIT licensed open source.

UNINSTALL
---------
Use "Add or remove programs" in Windows Settings, or Uninstall.exe in the
install folder. Your settings are kept unless you choose to remove them.
